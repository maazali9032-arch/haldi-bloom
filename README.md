# Haldi Bloom Invites

Build the premium, single-page, mobile-first cinematic Haldi wedding invitation exactly as requested. Make it hand-painted/watercolor Indian Haldi, not generic UI/cards. Use dynamic/configurable invitation data, multilingual instant switching (English/Hindi/Telugu, proper names untranslated), optional interaction-triggered music, non-persistent RSVP animations, event/venue/countdown sections, and public slug routing with neutral root and invalid/expired safe state using active_from/active_until. Make it ready for ZAR/Supabase; do not expose credentials and use fake env example values only. Prioritize fully responsive recomposed artwork across mobile through desktop, scroll-driven layered/parallax progressive reveals that reverse naturally, accessibility, no overflow. Include subtle shop branding near the bottom.
